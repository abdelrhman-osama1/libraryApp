# Library Management System (Console App)

A lightweight and robust console-based application built with **C#** demonstrating core **Object-Oriented Programming (OOP)** principles and in-memory data management.

## Features
- **Book Catalog:** Add and view available books with custom attributes.
- **Check-in / Check-out System:** Borrowing mechanics with strict business logic.
- **Borrowing Limit:** Restricts users from borrowing more than the allowed limit (max 3 books).
- **Search System:** Search books by title with clear availability status.
- **Input Validation:** Safe parsing and exception handling to prevent runtime crashes.

## Concepts & Technologies
- **Language:** C# (.NET)
- **Paradigm:** Object-Oriented Programming (Classes, Encapsulation, Methods)
- **Collections:** Generic Collections (`List<Book>`)
- **Control Flow:** Loops, Conditionals, and Console I/O
